# Icons

To generate the icons:

1. Open `create-icons.html` in Chrome
2. Right-click each canvas
3. Select "Save image as..."
4. Save with the correct filename:
   - `icon16.png` (16x16)
   - `icon48.png` (48x48)
   - `icon128.png` (128x128)

Alternatively, you can create your own icons with these specifications:
- Blue (#3498db) rounded square background
- White envelope icon
- Green (#27ae60) checkmark
